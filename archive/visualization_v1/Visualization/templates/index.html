🔐 Perceptual Hash Visualization

The image is resized to 8×8 pixels and converted to grayscale. Each pixel is compared to the average brightness to create a 64-bit binary hash. This hash is robust against minor image changes like compression or slight color shifts.

⚖️ Hash Comparison & Difference

The XOR (exclusive OR) operation compares both hashes bit-by-bit. Red areas show differing bits, while green shows matching bits. The Hamming distance is the total number of differing bits.
